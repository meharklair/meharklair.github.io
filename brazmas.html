Brazmas

Overview

Brazmas is an event check-in Android application developedme and 5 others using Java, Android Studio, JUnit, Espresso, Firebase, Figma, and UML. The app simplifies event management by allowing users to seamlessly switch between roles as both event organizers and attendees, making the check-in process more flexible and efficient.

More Info

Throughout development, the team followed the Agile methodology, which facilitated iterative improvements, constant feedback, and strong collaboration. By breaking the project into manageable sprints, we had the ability to adapt to changing requirements, allowing for more efficient progress throughout the Software Development Life Cycle. The team followed structured phases such as planning, design, development, testing, ensuring high-quality results at each stage.

To maintain reliability, JUnit and Espresso were used for unit and integration testing, ensuring smooth user interactions. Firebase facilitated real-time data storage and authentication, enhancing scalability. Additionally, Continuous Integration (CI) and Continuous Deployment (CD) practices were implemented to automate testing and deployment, streamlining development and reducing errors.
