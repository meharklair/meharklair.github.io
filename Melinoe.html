Melinoe

Overview

Melinoe is a command-line malware scanning tool that is developed in Python. I wanted to mix my passion for software development with my growing interest in cybersecurity. But I didn't want to make just anything; I wanted to create something both impactful but also fun to program and design, this ended with Melinoe. Melinoe uses the power of YARA rules, a widely used pattern matching tool that was specifically designed to detect malware. Alongside this it uses a malware signature database downloaded from Malware Bazaar.
