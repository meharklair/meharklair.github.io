Melinoe

Overview

Melinoe is a command-line malware scanning tool that is developed in Python. I wanted to mix my passion for software development with my growing interest in cybersecurity. But I didn't want to make just anything; I wanted to create something both impactful but also fun to program and design, this ended with Melinoe. Melinoe uses the power of YARA rules, a widely used pattern matching tool that was specifically designed to detect malware. Alongside this it uses a malware signature database downloaded from Malware Bazaar.

Conclusion & Future

Melinoe is still an evolving project, but I have made the GitHub repository public as it is currently in a functional state. While it effectively scans for malware using YARA rules and hash-based detection, there is still room for improvement and expansion. As I continue to grow my understanding of malware detection techniques, software optimization, and security best practices, I plan to enhance Melinoe with new features and refinements.

Looking ahead, I aim to transform Melinoe into a more comprehensive security tool. One of my key goals is to develop a real-time file monitoring system, allowing it to function similarly to an Intrusion Detection System (IDS). This would enable continuous scanning and alerting when suspicious files are detected. Additionally, I plan to introduce Linux support to make Melinoe more versatile across different operating systems. Also, I want to implement is multithreading, which will significantly improve performance by allowing concurrent scanning of multiple files, reducing processing time.

As I continue refining Melinoe, I hope to not only improve its effectiveness but also contribute to the open-source security community by sharing insights and improvements along the way. This project has been an excellent opportunity for me to apply and expand my skills, and I look forward to seeing how it evolves in the future.
