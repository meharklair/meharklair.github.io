Melinoe

Overview

Melinoe is a command-line malware scanning tool that is developed in Python. I was starting to get into cybersecurity and I wanted to combine it with software development. I didn't know what to make but then I found Yara rules which I thought was really cool. Yara rules are a widely used pattern matching tool that was specifically designed to detect malware. I made it so the user can specify their own Yara rules but also wrote some of my own (work in progress (╥﹏╥) ). I also wanted more general matching so I included a signature database from malwareBazaar. Also I themed after a game I really like (Hades 2) because things without themes are boring.

Conclusion & Future

Melinoe is still an evolving project, but I have made the GitHub repo public as it is currently in a usable state. While it works for scanning malware, there is still a lot of room for improvement. As I continue to grow my understanding of malware detection techniques, software optimization, and security best practices, I plan to continue to improve Melinoe.

In the future, one of my key goals is to develop a real-time file monitoring system, allowing it to function similarly to an Intrusion Detection System (IDS). This would enable continuous scanning and alerting when suspicious files are detected. Additionally, I plan to introduce Linux support to make Melinoe more versatile across different operating systems. Also, I want to implement is multithreading, which will significantly improve performance by allowing concurrent scanning of multiple files, reducing processing time.
